# JWT-API — Sistema de Gestão de Biblioteca

API RESTful desenvolvida em **Node.js + Express 5 + Sequelize + SQLite + JWT** para o gerenciamento completo de uma biblioteca, contemplando autenticação com **Access Token + Refresh Token (com rotação)**, controle de acesso por perfil (**Administrador** e **Atendente**), cadastro de categorias, autores, livros, leitores e fluxo transacional de empréstimos e devoluções.
